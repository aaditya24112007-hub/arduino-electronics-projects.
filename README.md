
# Project 03: LED Fading Using Arduino PWM

## Overview
An Arduino Uno project that gradually increases
and decreases an LED's brightness using PWM.

## Components
- Arduino Uno
- Breadboard
- LED
- 270 ohm resistor
- Jumper wires

## Connections
- Arduino pin 9 -> resistor -> LED anode (+)
- LED cathode (-) -> GND

## Concepts Learned
- Pulse Width Modulation (PWM)
- analogWrite()
- for loops
- Digital output control

## How It Works
The code changes the PWM value from 0 to 255,
then from 255 back to 0, creating a fading effect.

Built and tested successfully.
